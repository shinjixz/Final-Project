# 📘 คู่มือผู้ใช้ (User Guide) — Smart Art & Palette Sentiment Analyzer

ระบบรับข้อความภาษาอังกฤษ วิเคราะห์อารมณ์ (joy, sadness, anger, fear, love, surprise) แล้วแนะนำจานสี 8 สี ธีม และฟอนต์สำหรับงานออกแบบ

มี 2 แบบให้เลือกใช้:

| แบบ | เหมาะกับ | ต้องติดตั้งไหม |
| :--- | :--- | :--- |
| **Web Dashboard** | ดีไซเนอร์ทั่วไป ใช้งานเร็ว สกัดสีจากรูป | ไม่ต้อง เปิดเบราว์เซอร์ได้เลย |
| **Python CLI** | นักพัฒนา ต้องการเก็บประวัติ ค้นหา/กรอง/เรียง ส่งออกไฟล์ ประมวลผล CSV | Python 3.10+ |

---

## 1. Web Dashboard

1. เปิด https://peeraphatda.github.io/Final-Project/ (หรือรันในเครื่อง: `cd web && python -m http.server 8000` แล้วเปิด http://localhost:8000)
2. พิมพ์ข้อความภาษาอังกฤษ เช่น `I feel so happy today` แล้วกด **วิเคราะห์อารมณ์**
   - ครั้งแรกเบราว์เซอร์จะดาวน์โหลดโมเดล AI (ใช้เวลาสักครู่ ครั้งต่อไปเร็วขึ้น)
   - ถ้าโหลดโมเดลไม่ได้ ระบบจะใช้ **โหมดสำรอง (offline)** และแสดงข้อความแจ้ง — ค่าความมั่นใจจะมีคำว่า `(offline)` ต่อท้าย
3. กด **อัปโหลดรูปภาพ** เพื่อสกัดโทนสีจากรูป (ไฟล์รูปเท่านั้น ไม่เกิน 10 MB) — ผลจากรูปเป็น “การประเมินจากโทนสี” ไม่ใช่ค่าจากโมเดล AI
4. ส่งออกจานสีได้หลายรูปแบบ: ASE (Adobe), JSON, Figma tokens, HEX, RGB, HSL, Tailwind, CSS Variables
5. ปุ่ม **EN/TH** มุมขวาบนสลับภาษา
6. ประวัติ 10 รายการล่าสุดเก็บในเบราว์เซอร์เครื่องนั้น (ล้างได้ด้วยปุ่มลบประวัติ)

## 2. Python CLI

### ติดตั้ง
```bash
git clone <repo-url> && cd Final-Project
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt          # แบบเบา (ใช้โหมด keyword)
pip install -r requirements-ml.txt       # ถ้าต้องการโมเดล DistilBERT จริง
```

### เริ่มใช้งาน
```bash
python main.py              # ใช้ AI ถ้ามี ไม่งั้นใช้ keyword อัตโนมัติ
python main.py --offline    # ไม่โหลดโมเดล (เร็ว ใช้เดโมได้แม้ไม่มีเน็ต)
python main.py --db data/demo.db --no-color
```

### เมนู

| เมนู | ทำอะไร | ตัวอย่างอินพุต |
| :---: | :--- | :--- |
| 1 | วิเคราะห์ข้อความและบันทึก | `I am so excited about this project` |
| 2 | ดูประวัติทั้งหมด (ใหม่สุดก่อน) | – |
| 3 | ดูรายละเอียด + คำแนะนำธีม/ฟอนต์ + คู่สีที่ผ่าน WCAG | id `1` |
| 4 | แก้ไขข้อความแล้ววิเคราะห์ใหม่ | id `1` → ข้อความใหม่ |
| 5 | ลบรายการ (มีถามยืนยัน) | id `1` → `y` |
| 6 | ค้นหาจากข้อความ / ชื่ออารมณ์ / รหัสสี | `coffee`, `joy`, `#FFD700` |
| 7 | กรองตามอารมณ์, ความมั่นใจ (ใส่ `80` หรือ `0.8` ก็ได้), ช่วงวันที่ `YYYY-MM-DD` | `joy` → `50` → ว่าง → … |
| 8 | เรียงตาม `id/date/confidence/emotion/text` + เรียงรอง | `emotion` → `confidence` → `n` |
| 9 | ส่งออกจานสีเป็น `exports/palette_<id>.json` และ `.css` | id `1` |
| 10 | ประมวลผลไฟล์ CSV (ต้องมีคอลัมน์ `text`) | `data/sample_batch.csv` |
| 11 | สถิติ + รายงาน Insight อัตโนมัติ | – |
| 0 | ออก (`quit`, `QUIT`, `exit`, `ออก` ก็ได้) | – |

ช่องที่บอกว่า “เว้นว่างได้” กด Enter ข้ามได้

### โหมด Batch (ไม่ต้องเข้าเมนู)
```bash
python main.py --batch data/sample_batch.csv --output exports/result.csv
```
ไฟล์ผลลัพธ์มีคอลัมน์ `text, emotion, score, palette, error` แถวที่มีปัญหา (เช่น ยาวเกิน 1,000 ตัวอักษร) จะมีข้อความใน `error` โดยแถวอื่นยังทำงานตามปกติ

## 3. ข้อความเตือนที่พบบ่อย

| ข้อความ | สาเหตุ / วิธีแก้ |
| :--- | :--- |
| `ข้อความต้องไม่เป็นค่าว่าง` | พิมพ์ข้อความก่อนกด Enter |
| `ไม่พบรายการ id=… ในประวัติ` | ดู id ที่มีอยู่จากเมนู 2 |
| `id ต้องเป็นตัวเลข` | ใส่เลขจำนวนเต็มบวก |
| `ไม่รู้จักอารมณ์ …` | ใช้ joy, sadness, anger, fear, love, surprise หรือ neutral |
| `ไฟล์ CSV ต้องมีคอลัมน์ชื่อ 'text'` | แก้หัวคอลัมน์ในไฟล์ |
| `ใช้ keyword analyser แทนโมเดล AI` | ไม่ได้ติดตั้ง `requirements-ml.txt` หรือไม่มีเน็ต — ยังใช้งานได้ แต่แม่นยำน้อยกว่า |
| `ฐานข้อมูลเดิมเสียหาย ย้ายไปไว้ที่ …` | ระบบสำรองไฟล์เสียไว้ให้และสร้างใหม่แล้ว |

## 4. ข้อจำกัด
- วิเคราะห์ได้เฉพาะภาษาอังกฤษ (ข้อความไม่เกิน 1,000 ตัวอักษร)
- ประวัติฝั่งเว็บกับฝั่ง CLI แยกกัน
- โหมด keyword ตรวจจากคำศัพท์ จึงจับประชดประชันหรือประโยคปฏิเสธ (`not happy`) ได้ไม่ดี
